Rekapitulasi Spreadsheet BIWARA

Catatan harian keuangan ini ditautkan langsung ke Google Sheets resmi BIWARA. Salin baris data secara instan untuk ditempel langsung di sana dengan rapi.

Buka Spreadsheet
Panduan Rekapitulasi Baris Cepat:
  1. Pastikan kursor berada di sel paling kiri (Kolom Tanggal/Periode) pada baris baru di Spreadsheet Anda.
  2. Tekan tombol Salin Baris Rekap di atas.
  3. Kembali ke Spreadsheet Anda, lalu cukup tekan tombol keyboard Ctrl + V (atau Cmd + V di Mac).
  4. Seluruh data (Tanggal, unit bisnis, total omset, metode pembayaran, hingga profit) akan terisi otomatis secara horizontal ke kanan di kolom masing-masing secara sejajar!
INGIN SINKRONISASI OTOMATIS TANPA PASTE? (KLIK DI SINI)

Untuk mengaktifkan sinkronisasi otomatis latar belakang setiap kali admin menekan tombol "Selesaikan Pesanan", buat Google Apps Script di Spreadsheet Anda lalu tempel tautan Web App URL di bawah ini:

Script untuk Google Sheets: 
function doPost(e) {
  var sheet = SpreadsheetApp.openById("1nDXm0t9jrdENP2aV6xlrlbfqbENVxYgAOU4N1988tfk").getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.date,
    data.incomeCafeMandiri,
    data.incomeKoper,
    data.incomeProject,
    data.incomeBursa,
    data.grandTotal,
    data.incomeCash,
    data.incomeQris,
    data.periodicProfit
  ]);
  return ContentService.createTextOutput("Success");
}
